# Sydnie Lui Portfolio

A modern, playful one-page portfolio website for freelance clients and future employers.

## Files

- `index.html` - main site content
- `styles.css` - visual design and responsive layout
- `script.js` - small interactions for navigation and email copying
- `Sydnie-Lui-Resume.pdf` - downloadable resume

## GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository settings, open Pages.
3. Choose the `main` branch and the root folder.
4. Save, then use the generated GitHub Pages URL as the live portfolio link.
